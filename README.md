# 스터디플래너

서버 없이 열리는 웹앱입니다. 일정은 기기에 먼저 저장되고, 로그인하면 계정에도 저장되어 iPhone과 iPad가 같은 일정을 봅니다.

## 파일 (모두 폴더 없이 한 단계에 있습니다)
`index.html` `config.js` `supabase.js` `sw.js` `manifest.webmanifest` `icon-192.png` `icon-512.png` `apple-touch-icon.png` `setup-supabase.sql` `README.md`

GitHub에는 이 10개 파일을 그대로 올리면 됩니다. 폴더를 만들 필요가 없습니다.

## 1단계: 일단 올려서 써 보기 (로그인 없이)
1. GitHub에서 새 저장소(Public)를 만들고 위 파일을 모두 올립니다.
2. Settings > Pages에서 main 브랜치, `/ (root)`로 저장합니다.
3. 나온 주소를 iPhone Safari로 열고 공유 버튼 > "홈 화면에 추가"를 누릅니다.

이 단계에서는 `config.js`가 비어 있어서 로그인 화면이 없고, 일정은 그 기기에만 저장됩니다.

## 2단계: 계정 동기화 켜기 (Supabase)
1. supabase.com에 가입하고 New project를 만듭니다 (Free 플랜). 지역은 Seoul이 가깝습니다. 데이터베이스 비밀번호는 따로 적어 두세요.
2. 왼쪽 메뉴 SQL Editor > New query에 `setup-supabase.sql`의 내용을 전부 붙여 넣고 Run을 누릅니다. 내 일정은 나만 볼 수 있도록 하는 설정까지 들어 있습니다.
3. Authentication > Sign In / Providers(또는 Providers) > Email에서 "Confirm email"을 끕니다. 켜 두면 가입할 때 확인 메일의 링크를 눌러야 하고, 그 링크가 엉뚱한 주소로 갈 수 있습니다. 혼자 쓰는 앱이라 꺼도 괜찮습니다.
4. Project Settings > API(또는 API Keys)에서 Project URL과 anon 또는 publishable 키를 복사합니다.
5. GitHub에서 `config.js`를 열고 연필 아이콘을 눌러 두 값을 따옴표 안에 붙여 넣은 뒤 Commit changes를 누릅니다.
6. 1~2분 뒤 앱을 열면 로그인 창이 먼저 나옵니다. "처음이에요 · 회원가입"으로 가입하세요. 아이디는 이메일 형식입니다.
7. 다른 기기에서도 같은 주소를 열고 같은 아이디로 로그인하면 일정이 내려옵니다.

anon 키는 화면에 노출되어도 되는 키이고, 2단계의 SQL이 계정마다 데이터를 분리합니다. 비밀 키(service_role)는 절대 넣지 마세요.

## 동기화 규칙
- 페이지마다 마지막에 고친 기기의 내용이 이깁니다. 같은 페이지를 두 기기에서 동시에 고치면 나중에 고친 쪽만 남습니다.
- 오프라인에서도 쓸 수 있고, 연결되면 알아서 맞춰집니다. 앱이 열려 있으면 1분마다, 다시 열 때마다 확인합니다.
- 로그아웃하면 그 기기의 일정은 지워지고 (계정에는 남아 있습니다), 다른 계정의 일정이 섞이지 않게 합니다.
- "로그인 없이 이 기기에서만 쓰기"를 누르면 로그인 없이 쓸 수 있고, 나중에 화면 맨 아래의 "로그인"으로 합칠 수 있습니다.

## 알아둘 점
- 무료 플랜의 프로젝트는 일주일 동안 사용이 거의 없으면 일시 정지됩니다. 대시보드에서 Resume project를 누르면 데이터 그대로 돌아옵니다.
- 비밀번호 재설정 화면은 아직 없습니다. 비밀번호를 잊으면 대시보드의 Authentication > Users에서 계정을 지우고 새로 가입해야 하고, 이때 계정에 저장된 일정도 함께 지워집니다. 로그인되어 있는 기기가 남아 있다면 먼저 "백업 저장"으로 내보내 두세요.
- 파일을 고쳐 올릴 때는 `sw.js` 맨 위 `CACHE = 'studyplanner-v2'`의 숫자를 올려야 기기에 새 버전이 반영됩니다.
- 글꼴은 처음 열 때 인터넷에서 받아 보관합니다.
