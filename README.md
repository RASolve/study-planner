# 스터디플래너 (PWA)

서버 없이 돌아가는 정적 웹앱입니다. 데이터는 각 기기의 브라우저에 저장됩니다.

## 폴더 구성
- `index.html` 앱 전체 (화면, 스타일, 동작)
- `manifest.webmanifest` 홈 화면 앱 이름과 아이콘 정보
- `sw.js` 오프라인에서도 열리게 파일을 기기에 보관
- `icons/` 앱 아이콘

## 인터넷에 올리기 (무료 정적 호스팅 중 하나)
1. **끌어다 놓기 방식**: Netlify 또는 Cloudflare Pages의 직접 업로드 메뉴에 이 폴더를 그대로 끌어다 놓으면 주소가 생깁니다. 가장 쉽습니다.
2. **GitHub Pages**: 저장소를 만들고 이 폴더의 파일을 올린 뒤, 저장소 설정의 Pages에서 main 브랜치를 선택합니다.

주소는 반드시 `https://`로 시작해야 오프라인 기능이 켜집니다.

## iPhone / iPad에 설치
1. Safari에서 위 주소를 엽니다.
2. 공유 버튼 → "홈 화면에 추가"
3. 홈 화면의 "플래너" 아이콘으로 실행합니다. 주소창 없이 전체 화면으로 열립니다.

홈 화면에 추가하지 않고 Safari 탭으로만 쓰면, 오래 열지 않았을 때 저장된 데이터가 지워질 수 있습니다. 꼭 홈 화면에 추가해서 쓰세요.

## 백업
화면 맨 아래 "백업 저장"으로 JSON 파일을 내보내고, 다른 기기나 새로 설치한 앱에서 "백업 불러오기"로 합칩니다. 기기를 바꿀 때나 가끔 한 번씩 저장해 두세요.

## 수정본을 올릴 때
`index.html`을 바꿨다면 `sw.js` 맨 위의 `CACHE = 'studyplanner-v1'` 숫자를 올린 뒤 다시 올려야 기기에 새 버전이 반영됩니다.

## 나중에 동기화를 붙일 때
저장은 `index.html` 안의 `lsSave`와 `flush` 함수에 모여 있습니다. 이 두 곳을 계정 DB(Supabase, Firebase 등) 저장 코드로 바꾸면 기기 간 동기화로 확장할 수 있습니다.

## 알아둘 점
- 글꼴(Noto Sans KR, IBM Plex Mono)은 처음 열 때 인터넷에서 받아 기기에 보관합니다. 받기 전에는 기본 글꼴로 보입니다.
